# 🚀 Project HAIL MARY  - Sci-Fi Space Combat Game

> *"You were sent alone. You were humanity's last hope. You just don't remember it yet."*

## 📖 Overview

**Project HAIL MARY** is a sci-fi space combat game built in Unity, centered around the theme of **Memory**. Before the action begins, a cinematic intro sets the scene: you are **Ryland Grace** a scientist who wakes up alone aboard a deep-space spacecraft with no memory of his identity or mission. A cutscene reveals the truth through flashbacks and environmental storytelling: Earth's sun is dying, and he may be humanity's only hope.

Then the real game begins.

---

## 🎮 Gameplay

- **Intro Cutscene** - A cinematic sequence inside a spacecraft medical bay. Walk through the environment, trigger flashbacks, and discover the mission before combat starts.
- **Space Combat** - Pilot a fighter spacecraft through an asteroid field. Engage and destroy enemy ships using six-axis flight controls while dodging collisions and surviving missile attacks.

---

## 🕹️ Controls

### Space Combat
| Key | Action |
|-----|--------|
| W / S | Pitch Up / Down |
| A / D | Roll Left / Right |
| Q / E | Yaw Left / Right |
| Mouse Movement | Aim / Steer |
| Left Mouse Button | Fire Weapons |

---

## ✨ Features

- 🛸 **Six-axis space flight** : full thrust, pitch, roll, and yaw mechanics
- 🤖 **AI enemy ships** : built with PID Controllers for dynamic, reactive behavior
- 💥 **Combat systems** : lasers, missiles, shields, and explosion effects
- ☄️ **Asteroid field** : environmental hazards and collision detection throughout
- 🎬 **Cinematic intro** : camera wobble, emergency lighting, flashbacks, and scene transitions
- 🎨 **Modern UI** : radar tracking, enemy reticles, and menus built with Unity UI Toolkit (UXML + USS)
